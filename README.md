每个目录里放的是**完整可编译工程**（含 Keil 工程文件与厂商库），用 Keil MDK5 打开对应的 `.uvprojx` 就能编译，不需要另外补库。我自己写的部分在这些位置：

## 说明

- 仓库按原工程整份提交，厂商库（STM32 标准库 / HAL / CMSIS / FreeRTOS）一并保留，克隆下来即可用 Keil 编译。
- 编译产物（`.o`、`.crf`、`.axf` 等）与个人设置文件通过 `.gitignore` 排除，不占用仓库体积。
- 部分第三方驱动文件是 GB2312 编码，GitHub 网页上这些文件的中文注释会显示为乱码，用 Keil 打开显示正常。
- 三场比赛共用一套自建的 BSP + FreeRTOS 任务框架，所以目录结构相似，业务逻辑各自实现。
- 代码是比赛现场用的调试版本，保留了当时的调试痕迹（注释掉的实验代码、临时打印等）。

## 用到的技术

- 主控：STM32F407（标准库与 HAL 两种工程）
- RTOS：FreeRTOS（原生 API 与 CMSIS-OS v2 两种用法）
- 通信：UART、UART + DMA 空闲中断、CAN、I2C/SPI（显示与存储外设）、自定义定长帧协议（帧头/帧尾 + CRC8/CRC16）
- 控制：增量式 PID（积分分离、微分低通、死区、输出限幅）、加权偏差循迹、路径与比赛状态机
- 工具：Keil MDK5、STM32CubeMX、Git

## 第三方代码说明

STM32 标准库 / HAL / CMSIS、FreeRTOS 内核、步进电机协议驱动（Emm_V5，基于厂商代码修改）与 OLED / TFT 显示驱动为第三方或基于第三方修改；任务划分、控制算法、通信协议与各外设应用层驱动为自行实现。
